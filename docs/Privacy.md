# Privacy Notice

## Overview

BUPT International School TA Recruitment System is a local JavaFX desktop prototype for teaching assistant recruitment workflows.

## Data Stored

The application may store the following data locally:

- User account records
- Job postings
- TA applications
- Applicant profile information
- Resume metadata and uploaded CV files
- Audit log entries for key actions

## Authentication

Passwords are not stored as plain text. The prototype stores password hashes and compares login input against those hashes during authentication.

## Data Use

Stored data is used only to support role-based recruitment workflows inside this application, including job browsing, job management, applications, applicant review, workload checks, and administrative monitoring.

## Local Storage

This prototype stores data in local files under the project data directory. It does not provide external account login, third-party authentication, or external data sharing channels.

## User Responsibility

Users should avoid entering unnecessary sensitive personal data into free-text fields and should only upload CV files intended for recruitment review.
